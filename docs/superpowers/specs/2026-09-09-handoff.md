## Things that will bite the next session

- **A new agent is disabled per organisation.** `agent_enablement` — a run
  against a disabled agent is silently skipped with only a container log line.
  This cost an hour today.
- **Agent keys are hyphenated.** `brief-writer`, not `brief_writer`.
- **Any new table with a `client_id` must go in `MOVE_SPECS`
  (`merge-clients-tables.ts`) and in `merge-words.ts`.** The merge test catches
  it; it caught `portal_purchases` and `supplier_costs` today.
- **Two flaky tests were fixed** by removing assertions that indexed into
  queries with no `ORDER BY`. If a test fails intermittently in an unrelated
  file, look for that before suspecting the change in hand.
- **`pnpm test` needs Docker running.** Postgres goes down when Docker Desktop
  is closed, and the failure looks like a code error.
